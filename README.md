# Ardaas

An iOS app for composing a personal **benti** into the Ardaas, saving it, and
reading the whole thing in situ — the canonical text with your own words in
the place they belong.

Written for one person's need and shared in case it is useful to others.

## What it does

- **Two Ardaas variants** — Standard (SGPC) and Buddha Dal — each bundled with
  the app and readable offline.
- **Your benti in its proper place.** Not appended at the end: inserted at the
  point in the text where a personal supplication actually belongs, which
  differs between variants and was settled against the Sikh Rehat Maryada and
  documented practice.
- **Three layers** — Gurmukhi, Roman transliteration and English — for the
  canonical text and for your benti alike, each independently toggleable.
- **Translation that runs on your phone.** Write your benti in English and it
  is translated to Gurmukhi entirely on device. Nothing is uploaded. There is
  no server, no account, and it works with no signal at all.
- **Or write in Gurmukhi directly**, and the transliteration is generated by a
  deterministic engine that needs no model.

## Scripture accuracy

The bundled text is the point of the app, so it is treated as the most
sensitive thing in the repository:

- Every change to canonical Gurmukhi is proof-read before it is merged.
- Sources are cited per variant in the content JSON and shown in the app's
  **About & Sources** screen.
- Structural decisions — above all *where the benti goes* — are researched
  against the Rehat Maryada and practice guides, and recorded in the pull
  request that made them.
- Tests pin the structure (segment counts, the benti slot's position, layer
  coverage), so a refactor cannot quietly move the text about.

If you find an error in the Gurmukhi, please open an issue. It will be treated
as the highest-severity kind of bug this project has.

## Building

The `.xcodeproj` is **generated, not committed**. Source of truth is
`project.yml` (XcodeGen).

```sh
brew install xcodegen
xcodegen                              # stock: no translation engine
xcodegen --spec project-onnx.yml      # with the on-device translation engine
open Ardaas.xcodeproj
```

Requires iOS 17+. `project-onnx.yml` is the shipping configuration; the stock
spec builds the same app with the Translate action hidden, which is useful
when you do not want to resolve the ONNX Runtime package.

## On-device translation

English → Gurmukhi runs locally using a distilled
[IndicTrans2](https://github.com/AI4Bharat/IndicTrans2) model (MIT licensed)
exported to int8 ONNX. The model is **not** bundled: it is downloaded once,
only after the user explicitly opts in and is shown the size, and can be
deleted from within the app.

Measured on an iPhone 15 Pro: ~359 MB download, ~582 MB peak memory while
translating, ~1.9 s per sentence. See `docs/translation/` for how that memory
figure came down from 1374 MB, and `docs/transliteration.md` for the
romanization scheme and its known limitations.

## Layout

| Path | What it is |
| --- | --- |
| `Ardaas/Models/` | Content loading, composition, transliteration |
| `Ardaas/Translation/` | On-device translation (opt-in model, ONNX) |
| `Ardaas/Views/` | SwiftUI screens |
| `Ardaas/Resources/` | The bundled Ardaas texts and occasion list |
| `ArdaasTests/` | Unit tests, including the content invariants |
| `docs/` | Research and decisions worth keeping |

## Contributing

Corrections to the scripture text are the most valuable contribution and are
very welcome — please cite a source. Code contributions are welcome too; note
that CI builds and tests every pull request on a macOS runner, and anything
touching canonical text needs a proof-read before it can be merged.
